# 하준이가 배운 무술 — 대본용 기억

2026-10-24 하준이와 아빠가 대화로 알려 준 기록. ‘배웠다’는 뜻이며 숙련도·대회 사용 허용·혼자 연습 가능 여부를 뜻하지 않는다. 이름을 안다고 바로 모두 성공하는 인물로 그리지 않는다.

## 배웠다고 확인한 기술

| 종목 | 기술 |
| --- | --- |
| 주짓수 | 오모플라타, 리버스 암바, 암바, 기무라, 키락, 초크, 백초크, 트라이앵글, 델라히바 가드, 힙범프, 하프가드, 스윕, 시저 스윕 |
| 유도 | 허리후리기, 밭다리후리기(원문 ‘받다리’), 발뒤축걸기, **안뒤축감아치기**, 안다리후리기(말하다 ‘안다리’로 다시 확인), 모두걸기 |
| 레슬링 | 더블렉 태클, 인사이드 태클, 스로우바이, 암드래그/팔 끌기(원문 ‘언드래그’), 앞목 굴리기, **엉치걸이**, 돌아빠지기, 레터럴 드랍, **두팔한팔**과 두팔한팔 방어, 클린치, 스프롤, 팔 끊기, 백으로 돌아가기 |
| 레슬링 움직임 | 태클 공방 중 네 발로 기어서 옆으로 이동하는 동작. 정식 기술명은 확인하지 않았으므로 이름을 임의로 붙이지 않는다. |
| 발차기 | 발차기도 배웠다고 이야기함. 이번 대화에서는 정확한 종류가 특정되지 않았다. 기존 태권도 설정과 혼동해 새 숙련 기술을 만들지 않는다. |

- ‘안디축 가마치기’, ‘투팔암팔’, ‘엉치거리’는 사용자가 각각 **안뒤축감아치기, 두팔한팔(레슬링), 엉치걸이**로 직접 정정했다.
- **하체 굴리기는 안 배웠다**고 명시했다. 배운 것으로 넣지 않는다.
- **십자 굴리기는 아니라고 답했다.** 이어 말한 ‘하나 점프’는 이름이 불분명하다. 십자 굴리기나 특정 기술을 배웠다고 확정하지 않는다.
- ‘초크’는 포괄적인 이름이다. 특정 초크 종류를 모두 배운 것으로 확대하지 않는다. ‘리버스 암바’의 구체적 변형도 아직 특정하지 않았다.

## 앞으로 이야기에서 지킬 취향

- 새로 만들거나 크게 고치는 한 편은 **최소 5분(기본 타임라인 300초 이상)**. 대사를 늘리거나 정지 자세를 붙여 시간을 채우지 말고 실제 공방을 늘린다.
- 기술을 목록처럼 강의하지 않는다. 상대의 시도 → 방어/균형 회복 → 빈틈에 맞춘 다음 시도 → 결과가 보이는 대련을 우선한다.
- 레슬링·유도·주짓수에 장기가 다른 곤충들이 서로 만나는, 양산박의 영웅호걸 같은 군상 이야기. 별명·개성·라이벌·우정과 재도전이 있다.
- 드래곤볼의 초사이언 같은 짜릿한 성장·각성 연출을 원한다. 빛과 바람은 꾸준한 훈련과 배움이 이어지는 순간의 상상 표현. 초능력으로 상대를 다치게 하거나 한 번에 모든 기술을 익히는 설정은 아니다.
- 하준이가 ‘나도 도장에서 배워 보고 싶다’고 느끼게 만든다. 집에서 목이나 관절을 혼자 조작하라는 지시로 끝내지 않는다.
- 이 목록은 여러 화에 나눠 사용한다. 한 시합에 전부 억지로 넣지 않는다. 실제 기술명이 같아도 포지션·상대 반응이 다르면 연결이 달라진다.
- 완성·검증 뒤 PR 생성, 병합, 운영 배포까지 별도 질문 없이 진행한다.
