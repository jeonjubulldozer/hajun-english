# 곤충 무술 도장 — 새 화 만들기 설명서 (GPT·Codex용)

하준이(초등 1학년, 7살)가 아빠와 같이 보는 곤충 무술 애니메이션이다.
장면과 그림·움직임은 `dojo/index.html`, 음성 요청·저장은 `dojo/voice.js`에 있다. 앱 설치는 `dojo/sw.js`가 맡는다.
**새 화는 장면 대본(`beat`)만 추가한다. 엔진 코드는 고치지 않는다.**
단, 사용자가 음성·동작 자체의 수정을 요청한 경우에는 해당 엔진을 수정하고 회귀 검사를 한다.

## 1. 이야기 원칙

- 주인공 시청자는 하준이다. 먼저 "나도 그런데" 하고 공감하게 만든 다음, 알면 뭐가 좋아지는지 보여 준다.
- 하준이는 유도·레슬링·주짓수·태권도를 같이 배운다. 아침 7시 개인 레슨이 피곤해서 빼먹고 싶어 하고, 유도 단체반도 자꾸 안 가려고 한다.
- 꾸준히 하는 친구는 자라고, 빼먹는 친구는 기술이 녹슨다(`rust`). 다시 돌아오면 녹이 벗겨진다. 누구도 망신 주지 않는다.
- 지는 것은 배우는 것이다. 넘어지면 낙법 하고 다시 일어난다.
- "선택은 내가, 결과도 내 것"을 아이 말로 보여 준다.
- 개인 레슨은 기술을 배우는 곳이고, 단체반은 같은 크기 친구들과 많이 붙어 봐서 그 기술을 내 것으로 만드는 곳이다. 둘 다 하는 친구가 제일 강해진다.
- 레슬링이 하준이 힘(위에서 누르는 힘, 태클, 체력)의 원천이다.
- 아이가 부모를 때린 일이나 신체 훼손은 넣지 않는다. 2026-10-24 사용자 요청으로 그늘패와 마을 수호의 판타지 갈등을 추가했다. 통쾌한 공방은 보여 주되 피·다리 절단·관절 파괴는 넣지 않고, 멈추거나 탭하면 놓는다.
- 곤충 사실과 무술 설명은 정확해야 한다. 모르면 넣지 않는다.
- 기술 설명은 레슬링연구소·김관장박사장·유니크 유도의 기초 강의를 우선 참고한다. 실제로 확인한 영상 URL, 구간, 자막 또는 설명을 기록한다. 제목·검색 요약만 보고 강의를 검증했다고 말하지 않는다. 접근하지 못한 자료는 미확인으로 표시한다.
- 특정 상황의 지시를 모든 종목·포지션에 적용하지 않는다. “눈은 상대 배꼽”, “무게는 무조건 앞으로”, “고개를 돌리면 반드시 넘어진다” 같은 일반화는 쓰지 않는다. 집중을 설명하려면 “상대의 움직임에 집중한다”처럼 이야기의 의도로 표현한다.
- 말은 7살이 알아듣는 쉬운 한국어로 쓴다. 한 문장은 짧게.
- 내레이션은 실제로 말하듯 쓴다. 인물의 말은 따옴표로 구분하고, 완성된 문장 사이에는 `\n`, 대화로 바뀌는 자리에는 `\n\n`을 넣어 대본을 읽기 좋게 정리한다. 줄바꿈을 고정 시간 쉼으로 바꾸지 않는다. 주어·조사 뒤에 불필요한 쉼표를 넣지 않고, 짧은 구절은 이어 읽도록 쓴다. 한 장면 전체를 한 번에 합성해 문맥과 음색을 유지한다.
- 새로 만들거나 크게 개편하는 화는 기본 타임라인 **300초 이상**으로 만든다. `하준_수련기록.md`를 먼저 읽고, 공격 → 방어 → 다음 시도가 이어지는 실제 대련을 중심으로 구성한다. 정지 장면이나 설명만 늘려 시간을 채우지 않는다.
- 마지막은 다 같이 인사("고맙습니다!")하고, 다음 화 예고로 끝낸다. 예고에서 하준이에게 질문 하나를 던진다.

## 4. 새 화를 넣는 위치

`index.html`에서 **가장 마지막** `const EP숫자=SC;` 줄(지금은 `const EP14=SC;`)을 찾는다. 그 바로 뒤에 아래 모양으로 넣는다. 숫자는 하나씩 올린다.

```js
SC=[];
/* ===== 14화 · 다시 온 그늘패 ===== */
beat({ ... });
beat({ ... });
const EP15=SC;
```

그리고 `const EPS=[ ... ];` 배열 끝에 한 줄을 추가한다.

```js
{name:'14화 · 다시 온 그늘패',tab:'14화',next:'다음 화 제목',beats:EP15,ch:[['처음','첫 beat id'],['장면 이름','beat id']]}
```

`tab:'특집'`을 넣으면 위 버튼 이름이 "특집"이 되고, 안 넣으면 "4화"처럼 자동으로 붙는다.
화면을 열면 마지막 화가 기본으로 열린다.

## 5. beat(장면 하나) 형식

```js
beat({
  id:'match1',                 // 이 화 안에서 겹치지 않는 이름
  dur:14,                      // 길이(초). 목소리가 더 길면 장면 끝에서 기다려 준다
  cam:camOf(500,1.15),         // 카메라 가운데 x, 확대(1~1.3). 여럿이 나오면 0.8~1
  bg:'night',                  // 밤 배경일 때만
  nosign:1,                    // 위 "곤충 도장" 간판 숨기기(제목·끝 화면·확대 안 한 장면)
  who:['cicada','stag'],       // 아래 자막 띠의 이름표
  cap:'짧은 자막 한 줄',          // 화면 아래 글자
  say:'제미나이 목소리가 읽을 내레이션. 쉬운 말로.',
  actors:[ ON('cicada',[ [0,'guard',{x:420,f:1}], [1.5,'shoot',{x:520,e:'out'}] ]) ],
  props:()=>{},                 // 곤충보다 뒤에 그릴 소품
  fx:()=>{ chip(0.3,2.5,'wr','태클!'); burst(1.6,560,G-110,'슉!',null,'whoosh'); },
  over:lt=>titleCard(lt)        // 첫 장면은 titleCard, 마지막 장면은 endCard
});
```

### 움직임 키프레임 `[시간, 자세, {값}]`

- `x` 엉덩이 위치(화면 0~960), `y` 바닥에서 띄우기(음수 = 공중), `f` 보는 방향(1 오른쪽, -1 왼쪽)
- `rot` 몸 전체 회전: 0 서 있기, `-1.57` 등으로 눕기(머리가 뒤쪽), `4.71` 앞으로 한 바퀴 넘어가 등으로 착지, `2*PI` 다시 일어남
- `tl` 상체 숙이기, `ex` 얼굴(0 웃음, 1 집중, 2 놀람, 3 눈웃음, 4 눈 감음, 5 졸림)
- 팔다리 직접 조절: `fah fae`(앞팔), `bah bae`(뒷팔), `flh flk`(앞다리), `blh blk`(뒷다리)
- `e:'out'`(빨리 시작), `'in'`, `'lin'`, 기본은 부드럽게
- 자세 이름은 아래 표에서 고른다.

| 자세 | 뜻 |
| --- | --- |
| stand | 서기 |
| guard | 태권도·준비 자세 |
| low | 레슬링 낮은 자세 |
| shoot | 태클 |
| squat | 쪼그려 앉기·들기 준비 |
| lift | 두 팔 머리 위로 들기 |
| grip | 유도 깃 잡기 |
| turn | 업어치기 들어가기 |
| finish | 던지고 난 자세 |
| chamber | 발차기 준비 |
| kick | 앞차기 |
| spin | 뒤후려차기 |
| tuck | 공중에서 웅크리기 |
| back | 누워서 가드(다리 들기, rot -1.5와 같이) |
| flat | 납작하게 눕기 |
| top | 위에서 누르기·무릎 꿇기 |
| sprawl | 스프롤 |
| sit | 앉아서 버터플라이 가드 |
| bow | 인사 |
| cheer | 만세 |

### 자주 쓰는 동작 묶음 (지금 코드에서 그대로 복사해 쓰면 된다)

- **안전한 암바:** 5화 `id:'tap5'`, `MOVES.armbar(거는 곤충, 받는 곤충)`. 손목 잡기 → 다리 넘기기 → 앉아서 자세 만들기 → 탭과 동시에 풀기 → 인사. 팔을 끝까지 펴거나 골반을 들어 꺾는 표현은 하지 않는다.
- **팔끌기와 버티기:** 5화 `id:'standing5'`, `MOVES.armDrag(거는 곤충, 받는 곤충)`.
- **더블레그 태클:** 4화 `id:'mmdad'`, `MOVES.doubleLeg(거는 곤충, 받는 곤충)`. 몸 낮추기 → 양쪽 무릎 잡기 → 옆으로 넘기기 → 일어나 인사.
- **몸을 둥글게 말아 구르고 일어나기:** 4화 `id:'kidrhino'`, 긴다리의 7~9.5초 키프레임. `curl`은 머리를 몸 쪽으로 당기는 정도이며, 구른 뒤에는 0으로 되돌린다.
- 위 세 `MOVES`는 `actors`와 `rig`를 함께 반환한다. `...MOVES.armbar('bang','cicada')`처럼 beat에 넣는다. `rig`는 두 곤충의 손·발 접촉을 맞추므로 actors만 떼어 복사하지 않는다. 동작의 시간표와 장면 길이를 함께 확인한다.
- **업어치기:** 2화 `id:'match'`
- **태클로 넘기기:** 1화 `id:'katy'`
- **발 잡혀서 넘어가기:** 특집 `id:'tkdonly'`
- **스프롤:** 1화 `id:'spar2'`
- **낙법:** 1화 `id:'spar1'`
- **누워서 스윕:** 1화 `id:'mantis'`
- **들어 메치기:** 1화 `id:'rhino'`
- **걸어서 등장:** `ON(id,frames,{walk:[시작,끝]})`

## 7. 확인과 올리기

1. 스크립트 문법 확인: `<script>` 안쪽만 꺼내서 `node --check`로 돌린다.
2. 브라우저에서 열어 위 버튼에서 새 화를 누르고, 장면 버튼마다 눌러 보며 곤충이 화면 밖으로 나가거나 겹치지 않는지 본다.
3. 커밋 메시지 예: `곤충 무술 도장 3화: 맴맴이의 첫 대회`
4. 기본 내레이터는 `Sulafat`(다정한 이야기 목소리)이다. 기존 기기도 새 내레이터 버전 최초 실행 때 한 번 전환하고 이후 직접 고른 목소리는 유지한다. `목소리 미리 듣기`로 암바 장면 설명과 다정한 격려 대사를 먼저 들어 본다. 스타일 문구만으로 품질이 검증됐다고 판단하지 않는다. 음성은 고른 방식(제미나이 또는 클라우드)과 목소리로만 만든다. 실패·한도 초과 때 다른 모델·다른 서비스·기계 음성으로 자동 전환하지 않는다. 사용자가 방식을 바꾸면 해당 장면부터 새 프로필로 다시 시작한다.
5. 음성 저장 키에는 서비스·모델·목소리·호흡 지침 버전·대사가 모두 포함된다. 과거 `목소리|대사` 형식으로 섞여 저장된 음성은 재사용하지 않는다. 다른 앱의 저장소는 지우지 않는다.
6. 음성이 준비되지 않으면 장면을 기다리고, 실패하면 멈춰 같은 목소리로 재시도하게 한다. 내레이션이 길어도 문장 중간에 잘라 다음 장면으로 넘어가지 않는다.
7. `node dojo/tests/voice.test.cjs`와 `python dojo/tests/browser.py`로 음성 전환·저장·재생·동작 회귀 검사를 한다. 브라우저 검사는 Playwright와 Chromium이 필요하다.
8. **가짜 음성을 사용한 자동 검사와 실제 한국어 음성 청취는 다른 검사다.** 실제 생성·청취를 못 했으면 완료했다고 말하지 않고, 검증하지 못한 부분을 PR에 명시한다. 실제 키는 채팅·코드·로그에 넣지 않는다.

## 8. 영어책도 같이 만들기 (하준이 영어 도장 앱)

각 화는 영어 챕터북으로도 들어가 있다: `lily/books-bugdojo.js` (영어 앱 서재의 「곤충 무술 도장 영어판」).
새 화를 넣었으면 영어책도 한 권 추가한다.

1. `python3 lily/tools/dump_eps.py eps.json` — 각 장면의 자세와 내레이션을 뽑는다.
2. `lily/tools/gen_books.py`에 새 화 `book(...)`을 기존 화와 같은 모양으로 추가한다.
   - 한 페이지 = `P(화 번호(EPS 위치), 'beat id', [영어 문장들], ch='Chapter N · 제목')`. 그림은 그 장면의 자세가 자동으로 들어간다.
   - 수준: 원어민 7~8세 챕터북. 과거형 서술, 문장 8~18단어, 대사 섞기. 3챕터, 9~12페이지.
   - 이름은 영어판 이름을 쓴다: 맴맴이 Mem-Mem, 번쩍이 Coach Flash, 집게 Coach Pinch, 꽉이 Coach Grip, 팡이 Coach Pop, 동글이 Dot, 팔랑이 Flutter, 긴다리 Longlegs, 반짝이 Sparkle, 윙윙이 Buzz, 콩콩이 Bob, 띵가 Strum, 굴리 Rolly, 단단이 Rocky, 뚜리 Chirpy, 꼬마뿔 Little Horn, 씽씽이 Zippy.
   - `quiz` 6개(choice 3, word 1, say 2 — 하나는 `free: True`), `words`(어려운 단어 → 한국어 뜻), `talk`(질문 3~4개).
   - 맨 아래 `IDX`에 `EPS` 배열 위치를 넣는다(영어책 → 「이 화 만화로 보기」가 그 화를 연다).
3. `python3 lily/tools/gen_books.py eps.json lily/books-bugdojo.js`
4. `lily/index.html`의 `BUG_DOJO_WORLD`(Lily가 아는 만화 줄거리)에 새 화 한 줄을 추가한다.
